# Linkage Message

Веб-мессенджер: вход по имени пользователя и паролю (без телефона и почты), профиль с аватаром из галереи и датой рождения, поиск и добавление контактов по юзернейму, личные чаты и группы/каналы в реальном времени с индикатором «печатает…», эмодзи, реакции на сообщения, редактирование и удаление сообщений, вложения (фото/видео/файлы/голосовые), истории (Stories), персональные алиасы контактов, системные чаты «Избранное» и «Linkage Notifications», настройки профиля/приватности/уведомлений/сессий, смена пароля и удаление аккаунта.

Также: **аудио- и видеозвонки** (WebRTC, 1:1) с громкой связью и включением камеры прямо во время разговора, история звонков в чате, **анимированные эмодзи** как в Telegram, видео в историях, отправка нескольких файлов сразу (перетаскиванием и вставкой из буфера) с прогрессом загрузки, отметки о прочтении ✓/✓✓ и счётчики непрочитанных, контекстное меню сообщений (реакции, ответ, копирование, пересылка, закрепление, редактирование, удаление), закреплённые сообщения, поиск по чату, закрепление и отключение звука у чатов, блокировка пользователей, управление участниками групп и выход из группы, черновики, разделители по датам, кликабельные ссылки и просмотр фото на весь экран.

Стек: HTML/CSS/JS (без сборки) + Firebase (Email/Password Auth «под капотом» + Firestore) + Cloudinary (хранение фото/видео/файлов чатов), деплой — статический хостинг на Vercel.

Полностью бесплатно: Firebase на тарифе **Spark**, Cloudinary на бесплатном тарифе — оба без привязки карты.

## 1. Настройка Firebase

1. https://console.firebase.google.com → создать проект.
2. **Build → Authentication → Get started → Sign-in method** → включите провайдер **Email/Password** (только первый переключатель; см. ниже, почему он нужен, хотя пользователи вводят только имя пользователя).
3. **Build → Firestore Database → Create database** (режим Production, любой регион).
4. Вкладка **Rules** в Firestore → вставьте содержимое [`firestore.rules`](./firestore.rules) → **Publish**.
5. **Project settings → General → Your apps** → `</>` Web → зарегистрируйте приложение (Hosting не подключать) → скопируйте `firebaseConfig` в [`public/firebase-config.js`](./public/firebase-config.js).
6. **Authentication → Settings → Authorized domains** → добавьте домен, на котором будет открываться сайт (например `<project>.vercel.app`); `localhost` там уже есть по умолчанию.

Карту привязывать не нужно, тариф Spark остаётся бесплатным.

### Как работает вход по имени пользователя без почты/SMS

Firebase Authentication из коробки не умеет «просто логин+пароль» — провайдер Email/Password требует что-то похожее на email. Поэтому при регистрации клиент сам генерирует случайный бессмысленный адрес вида `a1b2c3...@users.linkagemessage.app` и создаёт аккаунт на него — пользователь его никогда не видит и не вводит. Юзернейм и этот адрес связаны через документ `usernames/{username}` в Firestore. При входе клиент сначала находит по юзернейму этот адрес, а затем уже логинится им через Firebase Auth. Смена юзернейма в настройках просто переносит эту связь на новый документ — сам Firebase-аккаунт не трогается, поэтому пароль и вход продолжают работать.

### Роль «danik»

В [`firestore.rules`](./firestore.rules) юзернейм `danik` захардкожен как единственный аккаунт, которому разрешено писать в общий канал «Linkage Notifications» (коллекция `broadcasts`, читают все, пишет только он). Чтобы использовать эту возможность, зарегистрируйте аккаунт именно с юзернеймом `danik`.

### Составной индекс Firestore

Список чатов сортируется по времени последнего сообщения (`orderBy lastMessageAt`) при фильтре по участнику (`array-contains`) — Firestore для такого запроса требует составной индекс. При первом открытии списка чатов в консоли браузера появится ошибка со ссылкой вида `https://console.firebase.google.com/.../firestore/indexes?create_composite=...` — просто перейдите по ней и нажмите «Create index» (создастся за 1-2 минуты, потом ошибка исчезнет сама).

Истории (статусы) показываются только вашим контактам — для их запроса (`audience array-contains` + `orderBy createdAt`) тоже нужен составной индекс; ссылка на его создание так же появится в консоли при первом открытии.

### Звонки

Звонки идут напрямую между браузерами (WebRTC), а Firestore используется только для «рукопожатия» (коллекция `calls`). Чтобы они заработали:

1. **Опубликуйте обновлённые правила** из [`firestore.rules`](./firestore.rules) (Firestore → Rules → Publish) — без них звонки и блокировка не работают, остальной мессенджер работает и на старых правилах.
2. Сайт должен открываться по **HTTPS** (Vercel — да) или с `localhost`: браузеры дают доступ к камере и микрофону только так.
3. По умолчанию используются публичные STUN-серверы Google — этого хватает для большинства домашних и офисных сетей. Если звонок «соединяется» и обрывается (часто бывает в мобильных сетях), нужен TURN-сервер: бесплатный можно получить, например, на https://www.metered.ca/tools/openrelay/ и вписать в [`public/ice-config.js`](./public/ice-config.js).

### Сквозное шифрование

Личные чаты (1:1) шифруются автоматически — ничего включать не нужно. Как в Signal/WhatsApp, у каждого устройства (браузера) при первом запуске появляется своя пара ключей ECDH P-256 (WebCrypto); приватный ключ хранится только на этом устройстве (IndexedDB, неизвлекаемый), публичный — в профиле (`users/{uid}.e2eDevices`). Каждое сообщение шифруется случайным ключом AES-GCM-256, а этот ключ «заворачивается» отдельно для каждого устройства собеседника и каждого вашего (ECDH + HKDF). В Firestore лежит только шифротекст и заглушка «🔒».

Шифруются текст, ответы, подписи, закреп, записи о звонках, превью в списке чатов **и сами файлы**: фото, видео, голосовые, кружочки, музыка и документы шифруются отдельным ключом AES-GCM ещё до загрузки, на Cloudinary лежит только шифротекст (ключ файла едет внутри зашифрованного сообщения). Такие файлы не перекодируются сервером — голосовые и кружочки воспроизводятся в формате, в котором записаны. Не шифруются группы/каналы и «Избранное».

**История на всех устройствах.** Когда вы входите с нового устройства, ваши другие устройства, которые уже могут прочитать старые сообщения, «заворачивают» их ключи и для нового устройства (поле `enc.keys.<id>` с пометкой `by`) — переписка появляется везде, где открыт аккаунт. Для этого хотя бы одно старое устройство должно открыть этот чат после появления нового. Шифротекст при этом не меняется, а правила Firestore (`isKeyShare`) разрешают только добавлять новые ключи. В профиле собеседника есть «код шифрования» из эмодзи: если у вас обоих он одинаковый, ключи никто не подменял (код меняется, когда кто-то добавляет устройство).

### Отправить позже

Удерживайте кнопку отправки (или нажмите на неё правой кнопкой мыши) → выберите время. Сообщение сохраняется сразу, но собеседник увидит его только в назначенное время; превью, счётчик и уведомление обновит первое открытое в этот момент приложение любого участника чата. Отправитель видит запланированные сообщения в чате (с пометкой 📅) и может отправить их сразу или отменить.

### Эффекты, игры, опросы и другие фишки

- **Эффекты сообщений** — удерживайте кнопку отправки (или правый клик) и выберите 🎉 ❤️ 🔥 ❄️ 🎆 💸: у всех участников по экрану пролетит конфетти, сердца, огонь, снег, салют или деньги. Повторить — значок эффекта у времени сообщения. Там же: «Отправить без звука» (собеседник получит сообщение без звукового сигнала) и «Отправить позже».
- **Мини-игры** — отправьте 🎲 🎯 🏀 или 🎰 отдельным сообщением (или выберите в меню скрепки): результат выпадает случайно на стороне отправителя, все видят анимированный бросок, при выигрыше — конфетти.
- **Опросы** — скрепка → «Опрос»: до 10 вариантов, анонимный или публичный (видно, кто голосовал), один или несколько ответов, голос можно отменить. Голоса хранятся в поле `votes` сообщения (каждый может менять только свой голос — правило `isPollVote`).
- **Геопозиция** — скрепка → «Геопозиция»: карта OpenStreetMap с меткой, по нажатию открывается полная карта.
- **Форматирование** — `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, `||спойлер||` (скрыт, пока не нажмёшь). Горячие клавиши: Ctrl+B, Ctrl+I, Ctrl+Shift+X, Ctrl+Shift+M (код), Ctrl+Shift+P (спойлер).
- **Жесты** — двойной тап/двойной клик по сообщению ставит ❤️, свайп сообщения влево на телефоне — ответ.
- **Папки чатов** — «Все / Личные / Группы / Непрочитанные» над списком, со счётчиками.
- **Эмодзи-статус** — «Настройки → Профиль»: эмодзи рядом с вашим именем у всех (в шапке чата и профиле — анимированный).
- **Обои чата** — меню чата → «Обои чата»: 9 анимированных фонов, для одного чата или для всех (хранится на устройстве).
- **Ссылка на профиль** — «Настройки → Профиль»: ссылка вида `https://ваш-сайт/?u=username`; кто по ней перейдёт, сразу попадёт в чат с вами (после входа, если он ещё не вошёл).

### Голосовые и кружочки — одна кнопка

Кнопка справа в строке ввода: **нажатие** переключает микрофон ⇄ камеру, **удержание** — запись. Во время записи: отпустить — отправить, увести палец влево — отменить, вверх — «без рук» (запись продолжится, отправка — той же кнопкой). В кружке после «без рук» палец можно вести дальше вверх — это зум; ещё зум работает щипком, колёсиком мыши, ползунком справа и двойным тапом по кружку. Кружок — до 60 секунд, голосовое — до 5 минут.

Голосовые показываются своим плеером: волна громкости (записывается при съёмке), перемотка нажатием по волне, скорость 1×/1.5×/2×, после окончания автоматически играет следующее голосовое. Нужна настроенная загрузка файлов (Cloudinary).

### Треугольнички 🔺

В режиме кружка **дважды быстро нажмите** на кнопку записи: иконка кружка плавно превращается в треугольник, и сразу начинается запись «без рук» (зум, смена камеры — как у кружков). У треугольника по краю бежит блик, а его фишка — **калейдоскоп**: кнопка-шестигранник на сообщении раскрывает видео в шесть зеркальных граней, которые медленно вращаются; крутите калейдоскоп пальцем (с инерцией), нажатие в центр включает «призму» с переливом цветов.

### Настройки

- **Поиск по настройкам** — строка сверху находит любой пункт и подсвечивает его.
- **Оформление** (на этом устройстве, применяется сразу, с живым превью): шрифт (Manrope, системный, Nunito, Lora, JetBrains Mono), скругление сообщений, стиль своих сообщений (градиент / стекло / контур), скорость анимаций (плавно / обычно / быстро / без анимаций), живой фон вкл/выкл.
- **Безопасность**: код-пароль из 4 цифр (хранится только хэш PBKDF2), автоблокировка сразу / через 1 мин / 5 мин / час, «Заблокировать сейчас», 5 ошибок подряд — пауза 30 секунд; размытие чатов при сворачивании (в переключателе приложений).
- **Уведомления**: 5 звуков на выбор с прослушиванием, вибрация, тихие часы (без звука и вибрации, в том числе через полночь).
- **Приватность**: отчёты о прочтении (взаимно: выключив, вы тоже не видите чужих), «Кто может мне звонить» — все / контакты / никто (проверяется правилами Firestore).
- **Данные и память**: сколько занято на устройстве (черновики, обои, настройки, ключи и кэш), экономия трафика (кружки не проигрываются сами), очистка черновиков и обоев, сброс настроек устройства.
- **Экспорт чата** — меню чата → «Экспорт чата» сохраняет переписку в .txt.

### Эмодзи, файлы и жесты

- **Все анимированные эмодзи** — панель эмодзи содержит все ~600 эмодзи, у которых есть анимация Noto (`public/emoji-data.js`, сгенерирован из googlefonts/emoji-metadata и проверен по CDN): категории, поиск (по-английски и по популярным русским словам), «Недавние». Нажатие на большое эмодзи в чате проигрывает его на месте с «желейным» отскоком и брызгами частиц.
- **Отправка прямо в чате** — фото, видео, файлы, голосовые, кружки и треугольники сразу появляются в переписке пузырём с превью и круговой шкалой загрузки; ✕ — отменить, при ошибке ↻ — отправить ещё раз. Несколько файлов встают в очередь.
- **Файлы открываются на месте** — аудиофайлы играют во встроенном плеере (волна, перемотка, скорость), фото, отправленные «без сжатия», видны превью, PDF и текстовые файлы открываются во встроенном просмотрщике.
- **Перемотка кружков и треугольников** — во время воспроизведения со звуком потяните за ободок (бегунок показывает позицию).
- **Зум при записи** — щипком двумя пальцами (или колёсиком мыши / двойным тапом, или ведя палец вверх после «без рук»).
- **Выход из чата** — свайп вправо в любом месте чата на телефоне.

### Отправка фото и файлов

Выбранные (или перетащенные/вставленные) файлы открываются в окне предпросмотра: подпись, **«Подпись сверху»** (над фото, а не под ним), **«Скрыть под спойлер»** (фото/видео размыто, пока его не нажмут), **«Без сжатия»** (фото уходит файлом в оригинальном качестве), можно убрать лишние файлы.

### Уведомления

- Пока приложение открыто, новые сообщения из других чатов показываются баннером сверху (нажать — открыть чат, смахнуть вверх — закрыть) со звуком и вибрацией на телефоне.
- Когда вкладка свёрнута — системное уведомление. На телефонах (Android Chrome) они работают только через service worker — он лежит в `public/sw.js`, нажатие на уведомление открывает нужный чат.
- При первом запуске в списке чатов появляется плашка «Включите уведомления». В «Настройки → Уведомления» есть кнопка «Проверить уведомление».
- На iPhone веб-уведомления работают только если добавить сайт на экран «Домой» (Поделиться → «На экран „Домой“») — для этого добавлены манифест и иконки.
- Ограничение: без сервера нельзя получать уведомления, когда приложение полностью закрыто, — для этого нужен push-сервер (Firebase Cloud Messaging + Cloud Functions на тарифе Blaze).

### Архив

Смахните чат в списке влево (на телефоне) — он уйдёт в архив (в архиве тем же жестом возвращается обратно). Либо долгое нажатие / правый клик по чату → «В архив» (или меню чата). Архивированные чаты уходят из списка в строку «Архив» наверху со счётчиком непрочитанных; список хранится в профиле (`archivedChats`), поэтому одинаков на всех устройствах.

### Группы и каналы: приватность и права

- «Профиль группы → Приватность» (только админы): частная/публичная, пригласительная ссылка (`?join=<id>&code=<код>`, можно сбросить), кто может добавлять участников и кто может писать (все / админы).
- Нажмите на участника (админом): назначить/снять администратора, запретить писать, отправлять медиа или добавлять участников, удалить из группы. Всё это проверяется правилами Firestore, а не только интерфейсом.
- Участников при создании группы и при добавлении выбирают галочками из уже существующих чатов.

### Вложения через скрепку

Камера (нажать — фото, удерживать — видео), фото/видео/файлы, музыка, опрос, **список** (например, продукты — пункты отмечают все участники), **контакт** (карточка с кнопкой «Написать») и геопозиция.

### Истории, обои, вход

- Истории видят только ваши контакты (список фиксируется в момент публикации, поле `audience`; проверяется правилами Firestore). Комментарии к истории тоже видят только они.
- Истории можно комментировать (поле внизу при просмотре, история ставится на паузу); свои и любые комментарии к своей истории можно удалить.
- Обои чата можно загрузить из галереи («Меню чата → Обои чата → Из галереи»), хранятся на устройстве.
- Вход и регистрация идут по шагам: имя пользователя → (ник и фото) → пароль.
- Поиск по юзернейму — настоящий поиск по началу имени.

### Мелочи

- Двойной тап ставит «быструю реакцию» — её можно выбрать в «Настройки → Чаты».
- Стрелка ↑ в пустом поле ввода — редактировать своё последнее сообщение.
- 🎂 рядом с именем у контактов, у которых сегодня день рождения, и конфетти при открытии их чата.
- Счётчик символов, когда сообщение приближается к лимиту в 4000.
- Количество непрочитанных на иконке установленного приложения.

### Производительность

Сообщения и чаты вне экрана не отрисовываются (`content-visibility`), каскадные анимации проигрываются только для видимых элементов, а декоративные зацикленные анимации ставятся на паузу во время прокрутки. В «Настройки → Чаты → Качество эффектов» можно выбрать «Авто», «Максимум» (с преломлением стекла) или «Экономный». В режиме «Авто» на телефонах и слабых устройствах включается экономный режим, а если кадры начинают проседать — приложение переключается на него само.

### Анимированные эмодзи

Сообщения из 1–3 эмодзи показываются крупными анимациями, при наведении анимируются эмодзи в панели, реакции «взрываются» анимированным эмодзи. Анимации — [Noto Animated Emoji](https://googlefonts.github.io/noto-emoji-animation/) от Google (лицензия CC BY 4.0), загружаются с `fonts.gstatic.com`; проигрыватель [lottie-web](https://github.com/airbnb/lottie-web) (MIT) лежит в `public/vendor/`. Если анимация недоступна, показывается обычный эмодзи.

## 2. Настройка Cloudinary (хранение фото/видео/файлов в чатах)

Firestore хранит только текст и метаданные сообщений — сами фото, видео, файлы и голосовые загружаются напрямую из браузера в Cloudinary (без бэкенда), а в Firestore попадает только ссылка на файл.

1. https://cloudinary.com/users/register/free → зарегистрируйтесь (бесплатный тариф, без карты).
2. На Dashboard скопируйте **Cloud name** (например `dxxxxxx`).
3. **Settings (шестерёнка) → Upload → Upload presets → Add upload preset**:
   - **Signing Mode: Unsigned** (обязательно — иначе загрузка с клиента без бэкенда невозможна).
   - Сохраните и скопируйте имя пресета (**Upload preset name**).
4. Впишите оба значения в [`public/cloudinary-config.js`](./public/cloudinary-config.js):
   ```js
   export const CLOUDINARY_CLOUD_NAME = "dxxxxxx";
   export const CLOUDINARY_UPLOAD_PRESET = "ваш_preset";
   ```

Оба значения публичные по своей природе (unsigned-загрузка так и задумана Cloudinary) — секретный API-ключ нигде в клиентском коде не нужен и не используется. Пока файл не заполнен реальными значениями, кнопка-скрепка и голосовые сообщения будут показывать ошибку «Загрузка файлов не настроена».

## Как это работает

**Вход и регистрация — отдельная страница `/login`:**
- Одна форма. По умолчанию режим «Вход» (юзернейм + пароль). Внизу ссылка «Ещё нет аккаунта? Зарегистрируйтесь» переключает форму в режим регистрации (и обратно такой же ссылкой снизу).
- В режиме регистрации дополнительно показываются: аватар (фото из галереи, необязательно), ник (отображаемое имя), поле «Подтвердите пароль». У полей пароля есть иконка-глазик для показа/скрытия введённого текста.
- После успешного входа/регистрации — редирект на `/` (сам мессенджер).

**На главной странице нет вкладок** — сразу единый список чатов. Сверху всегда закреплены:
- **Избранное** — заметки самому себе (`users/{uid}/savedMessages`), видны только вам.
- **Linkage Notifications** — системный канал: сюда автоматически падают уведомления о входах в ваш аккаунт (`users/{uid}/systemChat`, видно только вам), а также общие объявления, которые может отправлять всем пользователь `danik` (`broadcasts`, видно всем).

Новый чат — кнопка с карандашом внизу справа открывает окно с тремя вариантами: «Новый контакт» (поиск по юзернейму), «Новая группа», «Новый канал». Поиск в самом сайдбаре тоже работает и ведёт к тому же результату для контактов.

**Контакты:**
- Через карандашик → «Новый контакт»: при добавлении нового (ещё не добавленного) пользователя обязательно нужно ввести имя (фамилия необязательна) — без имени кнопки «Добавить»/«Написать» покажут ошибку и не сработают. У уже существующих контактов, а также при быстром поиске в самом сайдбаре (без карандашика), имя не запрашивается — если оно не задано, везде вместо него показывается ник пользователя.
- Каждому контакту можно задать/изменить своё имя и фамилию позже (иконка карандаша в шапке открытого чата) — они показываются в списке чатов и в заголовке вместо ника пользователя, как в Telegram.

**Чаты:**
- Личные (1:1) — коллекция `chats/{chatId}/messages`, ID чата — детерминированная комбинация двух uid.
- Список чатов и сообщения обновляются в реальном времени через `onSnapshot`.
- Индикатор «печатает…» (только в личных чатах): при вводе текста клиент проставляет метку времени в `chats/{chatId}.typing.{uid}`, собеседник видит «печатает…» вместо статуса, если метка свежее ~6 секунд; метка снимается по таймеру простоя или сразу при отправке сообщения.

**Группы и каналы (`groups/{groupId}`):**
- Создаются через кнопку-карандаш: название, необязательное фото, участники добавляются поиском по юзернейму (создатель — владелец и единственный админ на момент создания).
- *Группа* — писать может любой участник; *канал* — писать может только админ (пока это создатель), остальные участники только читают.
- В группах над входящими сообщениями показывается имя отправителя (у каналов и личных чатов — нет, там и так понятно кто пишет).
- И группы, и обычные чаты показываются в одном списке, отсортированном по времени последнего сообщения.

**Сообщения — вложения, эмодзи, реакции, редактирование:**
- Кнопка со смайликом открывает сетку эмодзи, вставляет символ в поле ввода.
- Кнопка-скрепка позволяет прикрепить фото, видео, файл или GIF (обычный `<input type="file">`, без поиска гифок по API — просто загрузка файла с диска/из галереи). Фото и видео показываются превью прямо в чате, файлы — карточкой с именем и размером.
- Кнопка-микрофон записывает голосовое сообщение (`MediaRecorder`), после записи можно прослушать и отправить или удалить.
- Все вложения (фото/видео/файлы/голосовые) загружаются напрямую в Cloudinary (см. раздел про настройку выше), в Firestore попадает только ссылка на файл — лимит на размер отдельного файла ~25 МБ (клиентская проверка перед загрузкой), а не ~700 КБ, как было бы при хранении base64 в Firestore. Требует заполненного `public/cloudinary-config.js` — иначе вложения отправлять нельзя.
- Долгое нажатие/наведение на сообщение показывает реакции (эмодзи-пилюли), кнопку «Ответить» (доступна на любом сообщении, включая чужие) и, только для своих сообщений, кнопки «Редактировать»/«Удалить». Реакции может ставить любой участник чата/группы.
- Ответ на сообщение — цитата с именем автора и превью текста/вложения показывается над строкой ввода до отправки и внутри самого сообщения после отправки; клик по цитате в сообщении прокручивает к оригиналу и подсвечивает его (только если он ещё виден в текущей истории чата).
- Клик по трём точкам в шапке чата открывает меню «Очистить историю» (только у себя, сообщения остаются у собеседника) и «Удалить чат» (тоже только для себя — чат снова появится, если придёт новое сообщение).

**Истории (`stories/{id}`):**
- Фото-истории живут 24 часа, видны всем зарегистрированным пользователям (не только контактам — полноценной модели «подписчиков» пока нет).
- Добавляются через ленту сторис вверху списка чатов (свой аватар с «+»). Автор может удалить свою историю досрочно.
- Просмотр — полноэкранный оверлей с прогресс-баром, автоматически листает дальше, свайп/кнопки для навигации между историями разных пользователей.

**Карточка контакта/группы** — клик по аватару или имени в шапке открытого чата открывает окно с информацией: для контакта — аватар, имя, юзернейм, «был(а) в сети», «о себе», дата рождения (каждое поле показывается только если это разрешено настройками приватности того пользователя); для группы/канала — аватар, название, тип, количество участников.

**Настройки (клик по своему аватару в сайдбаре открывает список разделов; конкретный раздел открывается только по клику на него, с кнопкой «назад»):**
- *Профиль* — фото из галереи, ник (со счётчиком символов), юзернейм (смена через транзакцию), статус/о себе (со счётчиком символов), дата рождения (с кнопкой «Очистить»), дата регистрации (только для чтения).
- *Приватность* — кто видит время последнего захода, фото профиля, «о себе», дату рождения (у каждого — «Все» / «Только контакты» / «Никто»), и отдельный переключатель показа индикатора «печатает…» собеседнику.
- *Уведомления* — «Не беспокоить» (полностью глушит звук и системные уведомления), звук, системные уведомления браузера (Notification API, работают пока вкладка открыта — без push/service worker), превью текста, отдельный переключатель уведомлений из групп и каналов (не только из личных чатов).
- *Чаты* (новый раздел) — отправка по Enter (или Shift+Enter/кнопкой, если выключено — Ctrl+Enter отправляет в любом случае), размер текста сообщений (мелкий/обычный/крупный), компактный режим (меньше отступов между сообщениями), выбор цвета акцента интерфейса из 7 пресетов.
- *Язык* (новый раздел) — переключатель RU/EN для основных элементов интерфейса (меню, заголовки настроек, кнопки, плейсхолдеры полей); сообщения в чатах, имена контактов и системные алерты не переводятся — это не полноценная локализация всего приложения.
- *Сессии* — кнопка «Выйти из аккаунта»; смена пароля (с подтверждением текущего пароля и показом/скрытием вводимого); история входов, где текущая сессия отдельно помечена «Текущая сессия» (остальные можно «забыть» из списка); удаление аккаунта (требует повторного ввода пароля; удаляет юзернейм и профиль, аккаунт Firebase Auth удаляется последним).

## Структура данных Firestore

- `users/{uid}` — профиль: `username`, `displayName`, `avatarColor`, `avatarImage` (data URL или `null`), `bio`, `birthday`, `emojiStatus`, `pinnedChats`/`mutedChats`/`archivedChats`/`blocked` (массивы), `lastSeenAt`, `createdAt`
  - `privacy`: `lastSeenVisibility`, `avatarVisibility`, `bioVisibility`, `birthdayVisibility` (каждое `"everyone"`/`"contacts"`/`"nobody"`), `typingVisibility` (bool)
  - `notifications`: `muteAll`, `sound`, `desktop`, `preview`, `groups` (все bool)
  - `chatPrefs`: `sendOnEnter` (bool), `fontSize` (`"small"`/`"medium"`/`"large"`), `compact` (bool), `accentColor` (один из 7 пресетов)
  - `language`: `"ru"` | `"en"`
  - `users/{uid}/contacts/{contactUid}` — контакт: `addedAt`, `firstName`, `lastName` (алиас)
  - `users/{uid}/savedMessages/{id}` — «Избранное»: `text`, `createdAt`, `edited`, `editedAt`
  - `users/{uid}/systemChat/{id}` — личные уведомления: `text`, `createdAt`
  - `users/{uid}/sessions/{id}` — история входов: `device`, `createdAt`
- `usernames/{username}` → `{ uid, authEmail }` — индекс логина/уникальности (публично читаемый — нужен для входа до авторизации)
- `broadcasts/{id}` — объявления от `danik`, читают все: `text`, `senderId`, `createdAt`
- `stories/{id}` — `ownerId`, `image` (data URL), `createdAt` (клиент фильтрует по 24ч)
- `chats/{chatId}` — `participants`, `lastMessage`, `lastMessageAt`, `lastMessageSenderId`, `typing` (карта `uid -> timestamp`), `hiddenFor` (массив uid, «удалено у себя»), `clearedFor` (карта `uid -> timestamp`, «очищено у себя»)
  - `chats/{chatId}/messages/{id}` — `text`, `senderId`, `createdAt`, `edited`, `editedAt`, `reactions` (карта `emoji -> [uid]`), `imageUrl`/`fileUrl`/`voiceUrl` (ссылки на Cloudinary, опционально), `fileName`/`fileType`/`fileSize` (для `fileUrl`), `replyTo` (снимок `{ id, senderName, text }` цитируемого сообщения, опционально), `effect`, `game` (`{ kind, value }`), `poll` (`{ q, options, multi, anon }`) + `votes` (карта `uid -> [индексы]`), `location` (`{ lat, lng }`), `voiceUrl` + `duration` + `wave` (волна голосового), `captionAbove`, `mediaSpoiler`
- `groups/{groupId}` — `type` (`group`/`channel`), `name`, `avatarColor`, `avatarImage`, `ownerId`, `admins`, `members`, `lastMessage`, `lastMessageAt`, `lastMessageSenderId`, `hiddenFor`, `clearedFor`
  - `groups/{groupId}/messages/{id}` — `text`, `senderId`, `createdAt`, `edited`, `editedAt`, `reactions`, вложения (как в чатах)

## Известные ограничения

- Вкладка «Сессии» показывает только историю входов (устройство + время). Удалённо «выкинуть» другое устройство нельзя — для этого нужен Admin SDK/бэкенд, которого в этом проекте нет.
- Все настройки приватности (последний визит, фото профиля, «о себе», дата рождения) проверяются на клиенте — это ограничивает UI (и скрывает поля в карточке контакта/при рендере аватара), но не является полноценной серверной защитой: Firestore-правила не ограничивают чтение самого документа `users/{uid}` по полям.
- Английский интерфейс переводит весь текст приложения (включая всплывающие сообщения); содержимое, которое вводят пользователи, не переводится.
- Аккаунты, зарегистрированные до появления этого набора настроек, не имеют новых полей (`chatPrefs`, `language`, расширенных `privacy`/`notifications`) в своём документе — код везде подставляет разумные значения по умолчанию при их отсутствии, поэтому ничего не ломается, но при первом сохранении раздела «Чаты»/«Язык»/«Приватность»/«Уведомления» эти поля появятся в профиле.
- Статус «в сети» — эвристика по `lastSeenAt` (обновляется раз в ~45 сек и при возврате на вкладку), а не настоящий realtime presence.
- Уведомления браузера работают только пока вкладка/приложение открыты — не push-уведомления (для них нужен Firebase Cloud Messaging + Service Worker).
- Удаление аккаунта не подчищает старые чаты/сообщения/группы с другими пользователями (Firestore-правила не разрешают удалять чужие данные с клиента) — только профиль, юзернейм и сам аккаунт.
- Аватары (профиля и групп) и картинки историй по-прежнему хранятся как base64 внутри документов Firestore (это небольшие сжатые изображения, ~20-60 КБ, укладываются в лимит документа с большим запасом) — на Cloudinary переведены только вложения сообщений (фото/видео/файлы/голосовые), которые могут быть значительно больше.
- Firestore-правила больше не ограничивают размер вложений (это делает Cloudinary на своей стороне) — правила лишь проверяют, что в поле лежит строка-ссылка разумной длины, а не бинарные данные.
- GIF нельзя найти поиском — только загрузить файлом (через кнопку-скрепку), интеграции с Tenor/Giphy нет.
- Cloudinary настроен на unsigned upload preset — это означает, что кто угодно, кто знает cloud name и имя пресета (оба публичные, видны в исходниках сайта), теоретически может залить файл в ваш аккаунт Cloudinary напрямую (в обход самого мессенджера). Firestore это не затрагивает (ссылка попадёт в базу только если пройдут её собственные правила), но при разработке рекомендуется включить в настройках пресета Cloudinary ограничения по типам/размеру файлов и следить за использованием бесплатной квоты.
- Правила Firestore разрешают ставить/снимать реакцию любому участнику чата, но не проверяют, что человек меняет запись именно под своим uid внутри карты `reactions` — теоретически можно подделать чужую реакцию через прямой запрос к Firestore (не через UI). Не критично, но стоит иметь в виду.
- Для зашифрованных медиа Firestore-правила не могут проверить, что внутри: запрет «отправлять медиа» в группе проверяется для открытых полей вложений.
